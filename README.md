# Vitality Gym

Site institucional responsivo da Academia Vitality, com identidade preto/laranja, planos, horários, estrutura, localização e contato.

## Rodar

Site estático: abra `index.html` ou execute `npx serve .`.

## Lovable

Importe este repositório GitHub em um projeto novo. A sincronização/publicação depende da conexão no Lovable.

## Personalização

Substitua os dados de contato e endereço de exemplo em `index.html` pelos dados oficiais antes de publicar. Preços e horários foram transcritos de imagens e precisam de confirmação.
